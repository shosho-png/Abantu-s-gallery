## 📝 Making Changes

The complete guide to making changes is in **[BEGINNER_GUIDE.md](BEGINNER_GUIDE.md)**, but here's the quick version:

1. Open GitHub Desktop
2. Click Repository → Open in Visual Studio Code
3. Edit `index.html`
4. Press `Ctrl + S` to save
5. Preview locally (double-click `index.html` or use Live Server)
6. Switch to GitHub Desktop → Changes tab
7. Type commit summary
8. Click "Commit to main"
9. Click "Push origin"
10. Wait ~60 seconds, refresh live site
